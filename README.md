# Airport Management System: AeroNexus

Airport boards, a live aircraft map and like-for-like fare comparison, built with Vite + React (frontend) and Node.js + Express + MongoDB (backend).

The project lives in [`aeronexus/`](aeronexus/):

- [`aeronexus/HOW_TO_RUN.md`](aeronexus/HOW_TO_RUN.md): step-by-step guide to run it locally
- [`aeronexus/README.md`](aeronexus/README.md): architecture, data sources and checks
- [`aeronexus/backend/`](aeronexus/backend/): API, database and realtime server
- [`aeronexus/frontend/`](aeronexus/frontend/): the website
